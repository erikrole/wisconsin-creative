# Changelog

Release notes live in one place: `src/lib/releases.json`, shown publicly at
[wisconsincreative.com/releases](https://wisconsincreative.com/releases). Every
user-visible pull request adds an entry (CI enforces it).

Monthly [GitHub Releases](https://github.com/erikrole/wisconsin-creative/releases)
use CalVer `YYYY.M.N` and are generated from those same entries by
`npm run release` (see D-049 in `docs/DECISIONS.md`).

The pre-October 2026 changelog is archived in
[`docs/archive/CHANGELOG-2026-beta.md`](docs/archive/CHANGELOG-2026-beta.md).
