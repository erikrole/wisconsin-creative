What changed, and why

A second submit created a second reservation

Was

People could split one event's equipment across duplicate reservation rows, creating extra pickup work and unclear ownership.

Now

Compatible gear is added to the existing event plan. Different pickup details or a started pickup stop with a direct link to the existing plan.

Duplicate copied the old event context

Was

The action cloned title, dates, events, and equipment together, making accidental same-event duplication easy.

Now

Reuse gear opens a fresh composer, requires a different event, remembers pickup location, and rechecks every item.

Legacy cleanup was record-by-record

Was

Staff had no safe way to combine matching rows or update an event-day batch.

Now

Selection supports previewed merge, pickup-location changes, owner transfer, and cancellation with partial-progress truth.

Event gear state was a count

Was

Operators could see totals but not one readiness answer per person.

Now

Event detail shows one person row with item count, readiness state, and a visible combine cue when legacy plans remain.
