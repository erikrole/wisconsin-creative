What changed, and why

The reservation menu exposed an unsupported counter

Was

The shared location catalog flowed directly into the web reservation picker, so UW Field House could be selected as a pickup location.

Now

A reservation-scoped allowlist keeps Camp Randall and Kohl Center in the picker and bulk reservation control. Server checks reject unsupported or inactive reservation locations across create, edit, candidate, and draft paths.

Event selection could silently choose the pickup counter

Was

Selecting an event copied its mapped venue into the reservation location, even when that venue was not an operational pickup counter.

Now

Event selection still derives title and timing, but pickup remains an explicit counter choice. Existing event venues and historical Field House records are preserved.

Verification

  • Focused tests: 70 passing across pickup allowlist, reservation create/edit/draft routes, event defaults, and booking UI contracts.
  • Web gates: npx tsc --noEmit --pretty false, npm run lint, and npm run build:app pass.
  • Review capture: matched before/after fixture screenshots were captured at 700x700; 92,878 of 490,000 pixels changed (18.95%), with the difference bounded to the removed option row and expected content reflow below it.

Things to know

  • The global location catalog was not deleted or filtered: Field House remains available for event venue mapping, inventory context, and historical records.
  • No database rows were changed, no migration was needed, and no deployment or authenticated production acceptance was performed.
