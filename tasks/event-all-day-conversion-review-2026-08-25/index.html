What changed, and why

Timing mode was implicit

Was

The editor preserved the loaded allDay value and only sent startsAt/endsAt, so an all-day event could not become a timed event.

Now

The editor owns an explicit mode draft, sends a complete normalized window plus allDay when the mode changes, and keeps the crew/notification path atomic.
