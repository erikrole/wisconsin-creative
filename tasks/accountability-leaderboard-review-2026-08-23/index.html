What changed, and why

Accountability was easy to miss

Was

The link lived at the bottom of the Admin-only Operations group and search hid it from every other role.

Now

It follows Bookings in primary navigation and appears in search for Admin, Staff, and Student. Collaborator remains default-deny under D-041.

The chart repeated the table

Was

Nine anonymous-feeling bars used 419px without saying who was actually on the wrong side of the pattern.

Now

A 275px spotlight shows the top three with avatars, the active ranking value, current-overdue status, and one gentle jeer apiece.

Ranking changes felt mechanical

Was

Changing Volume, Time, or Recent swapped the report beneath static chrome.

Now

The podium exits and settles with a short one-shot transition, exposes an aria-live relationship, and honors reduced-motion preference.

Read access was coupled to cleanup access

Was

The entire route was Admin-only because export, exclusion notes, and cleanup controls shared the same surface.

Now

The server returns explicit capabilities. Staff and Student receive the named read-only evidence; Admin alone receives CSV and exclusion metadata/actions.

Verification

  • Focused contracts: 57 Accountability, route, service, RBAC, search, sidebar, and UI tests pass.
  • Static/build: TypeScript, focused ESLint, docs/codemap verification, whitespace check, and the 238-page build:app pass.
  • Authenticated Admin preview: Creative Admin login, page, and Accountability API return 200; the API returns nine rows plus Admin export/cleanup capabilities.
  • Browser render: 1440×1000 and 1024×900 show no horizontal overflow, no error overlay, and no console warnings/errors. Volume → Time reorders the podium after a visible one-shot transition.
  • Dev-only failure: one transient /accountability 404 occurred while two Next dev servers compiled the matched baseline in parallel; the browser never showed an error, the immediate retry returned 200, and the final route/API reads remained 200.
  • Student browser proof: not run because only the requested Admin smoke identity is available. Student access, redaction, CSV denial, and Collaborator denial are pinned by route and RBAC tests.

Things to know

  • Public or unauthenticated accountability publishing remains deferred; this is an authenticated internal surface.
  • The live /reports/overdue queue is unchanged. Accountability remains the historical pattern view, not the custody work queue.
  • CSV export, excluded-record count and notes, exclusion/restore controls, and their mutations remain Admin-only.
