Wisconsin Creative · local implementation review

15 additional small fixes

Read-path correctness, safer exports, and navigation recovery. No layout redesign, schema migration, or production mutation.

Evidence boundaries

Behavioral review only. No authenticated product screenshot or matched visual baseline was captured. Regression tests exercise real route wrappers with mocked identity/database boundaries and real helper functions; they do not prove a deployed browser session.

What changed, and why

1. Audit export date windows

Was

Malformed dates reached Prisma; reversed windows looked like empty exports.

Now

Return 400 before reading audit data.

2. Private CSV responses

Was

Audit, bookings, items and users downloads lacked an explicit no-store policy.

Now

All four CSV responses are private, no-store.

3. Collaborator export filter

Was

The Collaborator role was missing from the export filter allowlist.

Now

Exports use the same role predicate as the directory.

4. Area filter validation

Was

Unknown area values reached Prisma enum filters.

Now

Use the directory’s validated area predicate.

5. Location filter normalization

Was

Whitespace in location ids produced a different result from the directory.

Now

Trim location ids through the shared query builder.

6. Bounded roster exports

Was

The route loaded every matching user synchronously.

Now

Read at most 5,001 rows, export 5,000, and mark truncation.

7. Collaborator profile privacy

Was

Staff CSVs included fields hidden by the collaborator profile API.

Now

Staff CSVs retain name, role and title; private columns remain blank. Admin exports remain complete.

8. Stable directory pages

Was

Equal sort values had no unique tiebreaker.

Now

Append id ordering to every directory sort.

9. Stable capped history exports

Was

Rows with equal timestamps could change order around the 5,000-row boundary.

Now

Audit and booking exports use createdAt plus id ordering.

10. Spreadsheet escaping

Was

Leading whitespace bypassed client report formula protection.

Now

Protect whitespace-prefixed formula values.

11. Truncated download feedback

Was

A missing total-count header turned incomplete downloads into success messages.

Now

Both helpers retain warning severity without a total.

12. Unusable JSON errors

Was

JSON null leaked into failure copy as literal null.

Now

Null, arrays and primitives use the normal status-based fallback.

13. Renamed recent records

Was

Renaming the most recent item left the previous label stored.

Now

Update the label even when its URL is already first.

14. Corrupt recent storage

Was

Malformed JSON blocked every future recent-history write.

Now

The next visit rebuilds a valid cache.

15. Browser history metadata

Was

Filter synchronization replaced router/history metadata with null.

Now

Preserve the current history state while updating the URL.
