Consistent file names make work easy to find, hand off, and archive. Use this pattern across photos, video, graphics, and project files.

> [!IMPORTANT]
> Keep fields hyphen-separated. Keep the final description short, readable, and specific.

## Base pattern

```copy
SPORT-YYYYMMDD-CONTEXT-...
```

- `SPORT` — approved sport abbreviation.
- `YYYYMMDD` — event or release date.
- `CONTEXT` — opponent abbreviation for game-related work, or a short event name when there is no opponent.
- Add the file-specific fields after the base pattern.

> [!TIP]
> When there is no opponent, use the event or release name as the context — for example `Schedule Release`, not a made-up opponent code.

## File naming patterns

### Video

```copy
SPORT-YYYYMMDD-CONTEXT-CAMERA-PERIOD-CLOCK-Description.mp4
```

Use the period label that fits the sport, such as `Q2`, `H1`, or `P3`.

Example: `FB-20250911-IOWA-SLOW1-Q2-12.04-Edwards Jr pass to Kekahuna 26 yds, celebration.mp4`

### Photo

```copy
SPORT-YYYYMMDD-CONTEXT-PHOTOGRAPHER-SEQ-Persons shown.jpg
```

Use a zero-padded sequence number, such as `072`.

Example: `WBB-20260122-MARY-KROMKE-072-Ronnie Porter.jpg`

### Graphics

```copy
SPORT-YYYYMMDD-CONTEXT-Description.ext
```

Examples:

- `MSOC-20251001-ILL-Game Day.jpg`
- `FB-20260602-Schedule Release.jpg`

### Projects

```copy
SPORT-YYYYMMDD-CONTEXT-Description.ext
```

Examples:

- `MBB-20250811-ILL-Blackwell Stats.psd`
- `VB-20251009-MINN-Booth Player of the Week.proj`
