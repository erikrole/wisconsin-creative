Use the shared Media Drive to reach Creative files from Finder.

> [!IMPORTANT]
> Before you start, connect to the UW network or VPN and make sure your account has Media Drive access.

## Server address

The server is called Media Drive. Once connected, open the shared Media folder.

```copy
smb://ath01-nas.uwia.wisc.edu/users/
```

Use this exact address in Finder’s Connect to Server window.

## Connect from Finder

1. Open Finder, then choose **Go → Connect to Server…** from the menu bar.

![Go menu](https://qi9afrhhevnyvfmv.public.blob.vercel-storage.com/resources/1787746545513-CleanShot-2026-08-26-at-07.07.58.png)

2. Paste the address into the **Server Address** field.

![Connect to Server](https://qi9afrhhevnyvfmv.public.blob.vercel-storage.com/resources/1787746550366-CleanShot-2026-08-26-at-07.09.54.png)

3. Optionally click **+** to keep the address under **Favorite Servers** for next time.

![Favorite Servers](https://qi9afrhhevnyvfmv.public.blob.vercel-storage.com/resources/1787746555651-CleanShot-2026-08-26-at-07.10.41.png)

4. Click **Connect** and wait while Finder contacts the server.

![Connecting](https://qi9afrhhevnyvfmv.public.blob.vercel-storage.com/resources/1787746559772-CleanShot-2026-08-26-at-07.11.20.png)

5. Open the shared **Media** folder. You should see **ARCHIVE** and **RESOURCES**; choose the folder that matches your work.

![Media folder](https://qi9afrhhevnyvfmv.public.blob.vercel-storage.com/resources/1787746599496-CleanShot-2026-08-26-at-07.16.30.png)

## Keyboard shortcuts

> [!SHORTCUT]
> `⌘K` — Connect to Server
> `⇧⌘G` — Go to Folder
> `⌘↑` — Up one folder
> `⌘[` / `⌘]` — Back or forward
> `⌘F` — Search this location

> [!TIP]
> For a repeat connection, press `⌘K`, choose the saved server under Favorite Servers, and click Connect.

## If Finder cannot connect

> [!WARNING]
> If Finder still cannot connect, confirm that you are on the UW network or VPN, then retry. If you can connect but cannot see Media, ask the person who granted your access.
