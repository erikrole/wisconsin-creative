iOS · Schedule + app-wide relative days

Today Stays Today

If the app stayed open past midnight, the Schedule labelled today's events as "Tomorrow". Day labels now update when the date changes.

Evidence

There's no matched before/after pair. The bug only shows when the app stays open past midnight, and a simulator capture can't reproduce that. The reported screenshot is the user's own device; the after capture is a fixture run on GT Capture iPhone 18 Pro Max, light mode, at the top of the list.

What changed, and why

"Tomorrow" on today's events

Was

The day headers checked the clock only when they first drew. Nothing redrew them at midnight, so an app left open overnight kept Thursday's labels on Friday.

Now

A shared today value, set where the app starts, updates at midnight, on clock or time-zone changes, and when the app returns to the foreground. Headers, rows, the week strip and the list's first day all use it.

Day 2 of a multi-day event read "Now" a day early

Was

Saturday's "Day 2 of 2" row showed Now on Friday.

Now

Each day of a multi-day event shows Now only on its own day.

Same fix across the app

Was

Event detail, Published Schedule, Home due-today colors, Profile Next Up, notification groups, booking day labels and kiosk sections each checked the clock directly.

Now

They all use the shared today value. A guard test fails if any iOS code checks today, tomorrow or yesterday against the clock directly.

Verification

  • xcodebuild: Wisconsin and WisconsinKiosk build
  • CurrentDayTests: 2 tests pass, including the midnight boundary
  • vitest: 712 test files pass, 1 skipped (includes the new guard test)
  • ScheduleScreenshotUITests/testScheduleListCaptures passed on GT Capture iPhone 18 Pro Max
  • npm run verify:docs passes

Things to know

  • The fixture capture shows how the screen looks with the change. It can't show the screen changing at midnight; the unit tests and guard test cover that.
  • Web schedule views also read the current date when they draw, so a browser tab left open overnight can still go stale. That isn't covered here.
