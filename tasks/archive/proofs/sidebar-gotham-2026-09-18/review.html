What changed, and why

Destinations read as Gotham

Was

Nav labels used inline heading family at 500/600. Body font-synthesis: none cannot fake 600, so active type looked closer to Geist.

Now

Buttons use .brand-identity. Idle is Gotham Medium (500). Active is Gotham Bold (700).

Lockup and groups match the identity face

Was

UW Athletics and Team/Library/Operations were Geist Mono. The product name used inline heading family at 800.

Now

The overline, wordmark, and group labels are Gotham Medium/Black. Role captions stay Geist Mono.

Verification

  • Focused vitest: tests/web-sidebar-source.test.ts — 16 passed.
  • npx tsc --noEmit passed.
  • Authenticated Chromium: computed font-family Gotham on lockup (800), idle destinations (500), active Users then Accountability (700), group labels (500), account name (700). ADMIN remained Geist Mono. Account menu opened with Enter (Profile, Help, theme, Log out). Users and Accountability navigation worked. Settings received focus; Enter did not change the route in this session.
  • npm run build:app was not run; the local preview server owns .next.

Things to know

  • Phone-width web and light appearance were not recaptured. The sidebar stays Wisconsin dark in both themes.
  • A Next.js issues badge stayed on the Users profile during capture; it was not diagnosed as part of this type change.
  • Unrelated dirty settings, schedule, and page-chrome work was left untouched.
