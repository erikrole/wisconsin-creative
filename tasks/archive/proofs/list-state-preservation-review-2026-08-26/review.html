What changed, and why

The list context was lost on detail return

Was

Schedule filters and view position lived only in the mounted hook, while Items used raw history replacement. Opening a detail route could return to the default list.

Now

Schedule serializes its current view and filters, and Items writes its existing query through the App Router. Back/Forward can rehydrate the same operator context.
