Brand assets on iPhone

Internal roles can open a logo or PDF from Browse. Folder create, upload, and version restore stay on the web.

This environment has no Xcode and no iPhone 18 Pro Max simulator, so there is no before or after screenshot. The comparison is the source contract, not a picture of the screen.

What changed, and why

Browse can open the file library

Was

Brand assets lived on the web. The phone could read Guides, which are Markdown, and had no way to open a logo or PDF at a venue.

Now

Browse adds Brand assets for every role except collaborator. The list is the current folder, with search and a Name, Recent, or Type sort.

A logo or PDF opens on the phone

Was

Opening the file meant using the website.

Now

An image, SVG, or PDF at or under 40 MB opens in the file page. Larger files, video, fonts, and other types share from the authenticated download. A font says sharing does not install it.

Uploads stay on the web

Was

The website can create folders, upload, favorite, and restore an older version.

Now

The phone only reads the list and the current file. A file with no version says uploading stays on the web.
