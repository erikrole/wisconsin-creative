Notification badge repair — TestFlight 1.3 (33)

Push taps now read their notification, and the icon reconciles with the server unread count. Physical-device visual acceptance remains open.

What changed, and why

Push tap read state

Was

Opening a push navigated to its destination without marking the inbox row read.

Now

The destination opens immediately; the app marks that row read and fetches the current unread count.

Stale icon count

Was

An unchanged cached count skipped the system badge write, even when APNs had changed the icon.

Now

Every successful unread refresh reapplies the count, including zero. Writes are serialized.

Independent refresh

Was

Dashboard or trade errors and a shell refresh throttle could prevent badge reconciliation.

Now

Unread reconciliation runs independently; foreground push presentation uses a fresh server count.
