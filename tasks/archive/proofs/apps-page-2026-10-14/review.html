What changed, and why

Offload's version and file did not match

Was

The card said 1.1.2 and linked to releases/latest/download/Offload.dmg, which is now 1.2.0.

Now

Version 1.2.0, dated Oct 13 in Madison, requires macOS 15.0, and downloads Offload-1.2.0.dmg. A newer live release replaces that URL only when the release names an asset.

The iPhone app over-claimed checkout

Was

The line said the app reserves and checks out gear.

Now

The App Store sentence: reservations, schedules, and equipment lookup. Minimum iOS is 26.0 from the store listing, with the listing's home screenshot.

Radio Clip showed a version with no source

Was

Version 0.1.0 on a coming-soon card.

Now

No version. A source TODO records that no public README or release was found.
