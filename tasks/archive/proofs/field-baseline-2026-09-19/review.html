What changed, and why

Shared field default is 40px

Was

Input, NativeSelect, and default SelectTrigger were h-9 (36px). FormCombobox was locked to h-9 so it would not misalign those fields. Many pages papered over this with className=h-10.

Now

Those primitives default to h-10. FormCombobox inherits the default Button height. A form row lines up without a local override.

Default buttons match the fields

Was

Default Button was h-9; size=lg was already h-10, so raising the default alone would collapse the size ladder.

Now

Default Button is h-10. size=lg is h-11 (44px) so it stays distinct. sm, xs, icon-sm, and icon-xs remain density exceptions.

Local h-9 holdouts follow the baseline

Was

ItemInfoTab QR entry, Onboarding bulk-role Select, the booking wizard Link-to-event chip, and non-compact ClaimShiftAction still forced 36px.

Now

Those controls inherit or set 40px. Compact ClaimShiftAction stays h-8.
