What changed, and why

Overdue rows said "Due"

Was

An overdue checkout showed "Due today at 6:00 PM" in red, which reads like a deadline still ahead.

Now

Once a booking is overdue, the row and the detail view say "Was due …". The label logic moved to Models.swift and has unit tests.

The refresh row looked like navigation

Was

Companion data had a chevron, but clicking it refreshed instead of opening anything.

Now

It shows a refresh glyph, and a small spinner while a refresh is in flight.

Booking detail was mouse-only

Was

Getting back to the list meant clicking "All bookings", and the web action was a small link at the bottom. Opening a booking kept the list's scroll position.

Now

Esc goes back and Return opens the booking in the browser. There is a Copy Ref button that confirms the copy, and the view scrolls to the top when a booking opens.

No right-click actions on booking cards

Was

Booking cards had no context menu.

Now

Right-clicking a card offers Show Details, Open in Wisconsin Creative, and Copy Reference.

Hygiene

Was

The open-booking link was built by string interpolation. Timing and health-colour code was duplicated. Settings copy was left over from the rename ("Wisconsin Creative … never writes to Wisconsin Creative"). Release binaries included coverage instrumentation.

Now

The link uses the shared, query-encoded BookingDeepLink builder. Each helper exists once. The copy is rewritten. Release builds turn coverage off (523 → 0 __profc symbols).

  • vitest tests/macos-gearops-*.test.ts + tests/companion-*.test.ts: 54 passed, including new detail-keyboard and debug-only-fixture contracts

  • Installed to ~/Applications and launched: one process, the session restored from Keychain, and the menu bar shows the live count

Things to know

  • Captures come from a Debug fixture window with a title bar, not the real popover. They prove presentation only, not live projection data.
  • The installed build is Developer ID signed but not notarized, the same as 1.0.4. spctl reports Unnotarized Developer ID.
  • Esc, Return, the context menu, and the copy confirmation were checked by build and source contract, not by recorded interaction.
