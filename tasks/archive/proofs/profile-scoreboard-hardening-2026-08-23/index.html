What changed, and why

Pagination could revive a finished cursor

Was

A null final-page cursor fell back to the original response cursor, while overlapping or stale requests could append repeated rows.

Now

Cursor ownership distinguishes not-yet-loaded from end-of-list, aborts stale requests, blocks overlap, deduplicates pages, and exposes retry without discarding rendered rows.

Clients duplicated the current season

Was

Web and iOS sent a hard-coded 2026–27 season, creating a rollover drift point.

Now

Both clients omit season unless one is explicitly requested, leaving the authenticated API as the default-season owner.

Cross-user denial followed target lookup

Was

A collaborator denial path could query a requested target before rejecting access.

Now

The route rejects unauthorized cross-user requests before target lookup, while keeping self, staff, admin, visibility, and not-found behavior covered by the role matrix.

Highlights could reward tiny samples

Was

Best venue favored raw win rate, so a 1–0 venue could outrank a sustained 6–1 record; area ordering depended on encounter order.

Now

Web and iOS rank venue strength by win margin, then rate and volume; worked areas follow the canonical product order.
