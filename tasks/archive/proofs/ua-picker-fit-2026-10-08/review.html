What changed, and why

Size each kind of gear correctly

Was

Shoes could save without sizes, shirts supplied defaults for pants, and all hats were one size.

Now

Shoes and fitted hats require sizes. Pants and base layers start without shirt defaults. Slides use whole-size options and matching US profile systems. Drive Pant uses even waist sizes.

Keep saved choices recoverable

Was

Invalid old sizes could appear valid.

Now

Saved sizes remain visible but unavailable item sizes must be corrected. Color changes preserve quantity and size, with duplicate detection.

Verification

  • 53 focused pricing and route tests pass; 8 sizing/default regressions fail on the isolated pre-change source.
  • 11 Chromium checks pass, including color payloads, duplicate feedback, optional filtering, and item sizing.
  • Application-only build and changed-file lint pass. TypeScript reports only the same two existing errors in unrelated iOS test helpers.

Things to know

  • No commit, push, deployment, or database changes.
  • Icon Lo size range is verified, but its source does not identify the US size system. The user suspects men’s sizing; automatic defaults remain off until confirmed.
  • Exact sizing sources: FW27_AE_Headwear_Wisconsin.pdf pages 2, 6, 9; Wisconsin Licensed Footwear.pdf page 1; FW27 Wisconsin Pinnacle B2B.pdf (6021743). All are supplied local UA documents in Downloads.
