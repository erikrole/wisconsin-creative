Native New Reservation composer, end to end

New Reservation now asks for the next decision only: an event first, matching pickup/return chips, then gear with search above the list instead of under the cart.

After-only fixture evidence

iPhone 16 Pro (27.0) UDID E055DEBC-12B1-4E0F-BE11-1CFFF4A454DE, WisconsinPerformance scenario create-booking-events, light appearance. Erik’s reported screenshots are physical-device dark mode with live inventory, so they are not a matched before pair.

What changed, and why

Event Linked empty state

Was

Pickup, gameday kit, and Add note appeared before an event was chosen, so the sheet felt like a location form with a disabled Choose Gear.

Now

Event Linked shows Set Schedule From and Choose Event only. Pickup, kit, notes, and the title/when card wait until an event is selected.

Pickup vs Return date chips

Was

Return’s DatePicker used a minimumDate range, so compact iOS rendered 9/18/26 next to Pickup’s Sep 17, 2026.

Now

Both chips are unbounded compact DatePickers. Ordering is still clamped in the binding. Fixture Manual shows 9/18/26 on both rows; event-linked shows Sep 17, 2026 and Sep 18, 2026.

Gear search and cart

Was

iOS 27 put searchable under the cart. Conflict copy truncated. Conflicted rows still showed a plus. A disabled black Review sat next to No equipment yet.

Now

Search sits above the results. The system bottom search accessory is removed. Advisory copy wraps on a compact same-day window. Blocked rows show a pin or conflict mark. Review appears only after gear is selected.
