Signature Wrong-Slot Hardening

Two MBB players signed in the wrong roster slots on 2026-09-03. These changes make a wrong slot visible before Save, make the fix a roster action instead of raw SQL, and let staff add players missing from the official roster without a later import dropping them.

What changed, and why

Wrong slot was easy to miss

Was

The name was small text in the header, away from where the signer writes.

Now

Name and number on the signature line, plus a prompt to check it before saving.

Correcting a wrong slot took raw production SQL

Was

Reassigning captures meant hand-written SQL against production.

Now

An audited **Move signature to…** action moves the whole capture, with its original revisions, to a blank person. It checks versions, blocks during live saves, excludes shared Creative Staff signatures, and leaves the source blank so stale drafts can't save onto it.

Official imports dropped unofficial players

Was

Apply deactivated every member missing from the snapshot, including staff-added ones.

Now

Apply deactivates only imported members, and adopts a staff-added player by unique name if they later appear officially.

No way to add an off-roster player to a team

Was

Only the ad-hoc collection took manual signers.

Now

Add player on team rosters, seeded from the previous season when the name is unique; a removed same-name player is reactivated instead of duplicated.
