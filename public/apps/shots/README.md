# App screenshot provenance

These assets are product illustrations, not proof of live team or archive data. No screenshots contain a live booking, personal project, or private media. They are original captures or published images; no UI was generated or retouched.

- `fetch-*.jpg`: installed notarized Fetch **1.5.4 (11)**, Apple silicon release. Opening window, lookup of the public CleanShot 5.0 video, generated WAV-to-M4A conversion preview, and completed generated conversions. Native window captures, October 20, 2026. Dimensions in page metadata match the captured pixels.
- `offload-ingest.jpg`: public Offload **1.5.3 (81)** executable from the verified release DMG. A disposable bundle with a separate identifier/preferences shows generated Sony-card MP4/XML fixtures. This is presentation evidence, not a physical camera-card or archive-transfer acceptance claim. The installed 2.0 development app was not used.
- `radio-clip-preview.jpg`: local Radio Clip development build compiled October 12, 2026, with isolated session storage, a generated one-minute WAV and fictional sample plays. Not a public release. No real broadcast was opened or played.
- `media-lab-preview.png`: isolated Media Lab smoke-test library generated by `tools/make_smoke_site.py` and `tests/smoke/test_pages.py`, captured October 20, 2026. Generated color-bar media and fictional clip context. Not a public release or live archive.
- `wisconsin-*.jpg`: already-published Wisconsin Creative App Store screenshot artwork, version 1.2. Downloaded from Apple’s image CDN on October 20, 2026 at 1279×2778. Published demo content, not a capture of the production workspace.
